# IBB Website

Website for International Business for Bruins (IBB) at UCLA, rebuilt this year (2026). Deployed on Vercel. 

Live site: www.ibbatucla.com

## Pages

Home, Team (with a region filter), Work With Us (for clients), Join Us (for members), and Contact.

## Run it locally

Double-click index.html, or run this and open http://localhost:8765:

```
python3 -m http.server 8765
```

To deploy, upload the whole folder to Netlify, Vercel, GitHub Pages, Cloudflare Pages or any static host.
